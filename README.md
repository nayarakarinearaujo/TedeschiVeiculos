# 🚗 Tedeschi Veículos

## 💼 Sobre o Projeto  
Tedeschi Veículos é um site institucional desenvolvido para uma empresa do setor automotivo. O objetivo é apresentar os serviços oferecidos, fornecer informações de contato e reforçar a presença online da marca de forma profissional e responsiva.

A aplicação foi construída com foco na clareza das informações e em uma navegação intuitiva, garantindo uma boa experiência para os visitantes, tanto em desktop quanto em dispositivos móveis.

## ✨ Funcionalidades  
- Página inicial com apresentação da empresa  
- Seção de serviços oferecidos  
- Informações de contato e localização  
- Layout responsivo adaptado para diferentes telas  
- Navegação simples e direta  

## 🎨 Design  
O design do site foi elaborado com base em uma identidade visual sóbria, refletindo a seriedade e a confiabilidade da empresa no setor de veículos. As cores e tipografias foram escolhidas para transmitir profissionalismo e acessibilidade.

## 🛠️ Tecnologias Utilizadas  
- HTML  
- CSS  
- JavaScript  
- React
